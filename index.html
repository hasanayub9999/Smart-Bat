HOW TO READ THIS

Signals are not performance by themselves.

Angular velocity describes how quickly the sensor rotates. Acceleration describes changes in velocity and includes gravity. To estimate useful batting metrics, the system will need a known sensor orientation, calibration, a consistent mounting position, and carefully labeled practice trials. These charts currently use synthetic data only.

FUTURE CONNECTION

Hardware integration plan

Recommended first architecture:

  1. IMU sensor connected to a microcontroller.
  2. Microcontroller streams timestamped CSV readings.
  3. Python receives and validates the stream.
  4. Python exposes a local API or WebSocket feed.
  5. This dashboard displays live and saved session data.

The exact board and sensor will be selected before writing device-specific firmware.
